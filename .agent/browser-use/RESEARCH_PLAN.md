# Browser-Use Research Plan — Margin

## Target Categories
- Calm typing interfaces
- Focused productivity UI
- Premium dark/light UI
- Editorial typography
- Accessible motion
- Character-level feedback
- Progress/statistics UI
- Focus mode / zen mode
- Dialog/modal polish
- Responsive interaction

## Extraction Targets
- Color palettes and token systems
- Typography: font families, sizes, line heights, letter spacing
- Spacing rhythm (base unit, scale)
- Container widths and max-widths
- Border radius values
- Shadow depth systems
- Visual depth layering
- Hover and focus states
- Current-item / cursor indicators
- Progress indicators (bars, rings, etc.)
- Statistic presentation (WPM, accuracy, time)
- Modal/dialog transitions
- Stage transitions
- Reduced-motion handling
- Responsive breakpoints and behavior

## Constraints
Research must support:
- Accessibility (WCAG 2.1 AA)
- Readability
- Typing speed (zero perceptible lag)
- Low visual fatigue
- Performance (transform/opacity only)
- Reduced-motion compliance
- Minimal visual clutter

## Research Mode
DEGRADED — using public web research and MCP Browser tools. No browser-use Python automation.
