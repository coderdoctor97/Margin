# Keyboard click asset

- Filename: `key-click.pcm.json`
- Creator: Original asset generated for the Margin project
- Source URL: None; this is not a third-party recording
- License: CC0 1.0 Universal dedication (https://creativecommons.org/publicdomain/zero/1.0/)
- Attribution: Not required

The file contains a short, mono, signed 8-bit PCM waveform at 8 kHz. It was made by combining a manually shaped alternating impulse with a fast amplitude decay, then storing the samples as JSON so the source and generation characteristics remain inspectable. `KeyboardAudio` decodes the samples into a Web Audio `AudioBuffer` after a user interaction. No third-party audio or invented attribution is used.
